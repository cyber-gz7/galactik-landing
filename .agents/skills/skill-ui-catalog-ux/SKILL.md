# Skill: UI Catalog & Industrial Broadcast UX

## Capacidades y Responsabilidades
1. **Reparación de la Tabla de Minecraft Overlays**:
   - Corrección de textos encimados en columna izquierda (`Cualquiera`, `Regalo`, nombre) mediante flexbox desacoplado y espaciado consistente.
2. **Reparación del Grid de Catálogo de 1,770 Regalos**:
   - Grid de dimensiones óptimas (`repeat(auto-fill, minmax(118px, 1fr))`, `grid-auto-rows: 142px`), centrado de imágenes de regalos con drop-shadow y prevención de colapso de badges.
3. **Conector Rápido TikTok en Topbar**:
   - Input compacto `@usuario` con autoguardado + botón interactivo `[⚡ Conectar]` / `[🔴 Desconectar]` con LED de estado.
   - Timeout de handshake a 5 segundos y cierre inmediato de instancias previas ante reconexión.
4. **Depuración de Inicio y Eliminación de Facciones**:
   - Eliminación total de bloques "FACCIÓN: BUENOS / MALOS".
   - Guía Rápida de Transmisión en 3 Pasos y tarjetas de modo modernizadas.
5. **Erradicación de Marcas Externas**:
   - Reemplazo absoluto de toda mención "StreamToEarn / S2E" por "Biblioteca de Sonidos Galactk Studio".
